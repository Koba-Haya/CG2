# 3日スプリント: 「ゲームになってない」を潰す

期間: 2026-09-25(木) 〜 09-27(土) ※今日を含めて3日 / 想定稼働: 1日9〜10h(合計約28h)

長期計画は [PROJECT_ROADMAP.md](PROJECT_ROADMAP.md)。**このスプリントはそれを「通しで遊べる」一点に絞った短縮版**。
方針: **見た目の綺麗さより「最初から最後まで一本で体験できる」ことが最優先。仮置き(ImGui文字・単色キューブ)で構わない**
(先生の指摘自体が「仮置きすらしていない」なので、仮置きで通るならそれで満点に近づく)。

---

## 0. 現状の診断(コード確認済み)

| 先生の指摘 | 原因(実際にコードで確認したこと) |
|---|---|
| 敵を数体倒したら終わり | レール長270ユニット÷速度10 = **約27秒**。タイムラインは**4イベントのみ**(約14秒で打ち止め)。その後ボスキューブ(HP10)が出て終わり |
| 敵やギミックが1種類 | 実装は通常/タレット/突進の3種あるが、**プレハブが全部同じ白い`cube.obj`**。見た目では区別がつかない。ギミック(地形・障害物・アイテム)は皆無 |
| プレイヤーができることが少ない | 実装は移動/通常弾/ロックオン/回避ロールがあるが、**それを使う必然性がない**(敵が少なく、弾も避けなくていい、ロックオンする理由がない)。操作説明も画面に無い |
| リアクションがない | 撃破エフェクト・カメラシェイク・ポストエフェクトは既にある。**被弾/命中のSE・BGMが全く無い**(`AudioManager`はどこからも呼ばれていない)。敵の被弾フラッシュ・スコア表示・ボスの被弾表現も無い |
| 通しで体験できない | タイトル/クリア/ゲームオーバーは`#ifdef USE_IMGUI`の小さなボタンだけ。スコアHUDなし、ボスは`BossComponent::Update`が空で汎用射撃任せ |

**重要な発見**: 半分は「無いから作る」ではなく「ある物を見える形で繋ぐ」で解決する。新規実装は最小限にできる。

## 1. 完了の定義(3日目の夜にこれが全部YESなら勝ち)

## 3. Day 1 (9/25) — 「通しで遊べる背骨」を作る

> ゴール: 一本道で最後まで遊べて、勝ち負けの画面が出る。中身は薄くてよい。

| # | タスク | 目安 | 詳細 |
|---|---|---|---|
| D1-1 | **画面フロー(タイトル/クリア/ゲームオーバー)** | 1.5h | 各シーンで`ImGui::GetForegroundDrawList()`等で**大きな文字**を直接描画(日本語フォントはロード済み)。タイトル: ゲーム名+「SPACEでスタート」+操作説明。ゲームオーバー/クリア: 結果+「SPACE:リトライ / T:タイトルへ」。`services_.audio`から決定SEを鳴らす |
| D1-2 | **ゲーム内HUD拡張** | 1h | スコア(`score_`はGameSceneにある)、コンボ/撃破数、ボス登場後はボスHPバー。ImGui描画で可。`GameHUD`か`GameScene`に追加 |
| D1-3 | **ステージを長く+緩急** | 1.5h | `Game.json`のRailCameraのウェイポイントを延長して**約90秒〜2分**に(速度は`SetSpeed`)。単調な直線をやめ左右/上下のカーブを入れる。ボス直前は減速。※カメラは後ろを向けない仕様なので背後攻撃は設計しない |
| D1-4 | **敵配置を4→約25イベントに** | 2h | タイムラインエディタで配置。既存3種(通常/タレット/突進)だけで先に組む。序盤=通常のみ(操作を覚える)→中盤=タレット・突進混在→終盤=編隊+混成→ボス、の**難易度カーブ**を意識。新種類はDay2で差し込む前提でスロットを空けておく |
| D1-5 | **ボス v1** | 2.5h | `BossComponent`に`enum class Phase`+`switch`のステートマシン(文字列比較にしない=先輩フィードバック対応)。HP 10→**40〜60**。まずパターン2つ(①扇状の直進弾 ②プレイヤー狙いホーミング弾)。HP半分でフェーズ2へ。`EnemyShootComponent`直付けは外す。ボス出現時に画面フラッシュ+「WARNING」表示+BGM切替 |
| D1-6 | **音を鳴らす基盤** | 1.5h | `AudioManager::Load`をシーンInitializeで、`Play`をイベント箇所(発射/撃破/被弾/フェーズ移行/クリア)で呼ぶ。BGM(道中/ボス)ループ再生と`Stop`。ここでは**全部繋ぐ**ことを優先、音質は後回し |

**Day1終了チェック(夜に必ず実施)**: タイトルから開始して最後まで**自分で1回通しクリア**する。詰まった箇所を`Day2の頭`に書き出す。

## 7. やらないこと(誘惑への予防線)

- `GameScene.cpp`(1128行)のリファクタリング → 提出後のM4で。今はテストしづらくなるだけ
- 複数ステージ/ステージ選択 → 1ステージを濃くする
- 新規モデル作成・武器モデル差し替え・ロックオン演出の大改造
- カメラの後ろ向き攻撃(仕様上カメラは振り返れない)
- スプライトUIの作り込み(ImGuiの仮UIで通ればそのままでよい。**余った時間だけ**差し替える)
