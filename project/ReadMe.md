# 加点要素

## PostEffect

画面全体にかけるPostEffectは仕組み上同時に1つしか表示できないため、状況ごとに
どれを表示するかの優先順位をあらかじめ決めておき、ゲーム内で発生する出来事
（被弾・体力低下・ロックオン操作・敵の出現・ボスの出現など）に応じてプレイ中に
自動的に切り替わるようにした。デバッグ用のメニュー等から手動で切り替える実装では
なく、実際にゲームをプレイするだけで確認できる。

### Grayscale

プレイヤーの体力が残りわずか（瀕死）になっている間、画面全体をグレースケール表示にし、
危険な状態であることを視覚的に伝える演出として使用した。

- 確認方法: 敵の攻撃を受け続けて体力を残り1まで減らすと、画面がモノクロになる。
  体力が回復する、あるいは他の演出が優先される状況になると解除される。

### Vignette

プレイヤーが被弾し体力が減った瞬間、約0.3秒間だけ画面の周辺を暗くする表現を出し、
ダメージを受けたことを視覚的にフィードバックした。

- 確認方法: 敵の攻撃を受けて体力が減ると、その瞬間だけ画面の周辺が暗くなる。

### BoxFilter

新しい敵の群れが出現した瞬間、約0.5秒間だけ画面全体に軽いぼかしをかけ、
敵の出現にフォーカスが移るような演出にした。

- 確認方法: 新しい敵が出現するタイミングで、画面が一瞬ぼやける。

### GaussianFilter

ボスが出現した瞬間、約1.2秒間だけ画面全体に強めのぼかしをかけ、
カメラのフォーカスが切り替わるような演出にした。

- 確認方法: 道中の敵を倒しながら進み、ボスが出現する瞬間に画面が一時的にぼやける。

### LuminanceBasedOutline

ボスとの戦闘中（ボス出現からボスを倒すまでの間）、明るさの差をもとにしたアウトライン
表現を画面全体にかけ続け、通常の戦闘とは異なる緊張感のある見た目にした。

- 確認方法: ボス出現時のぼかし演出が終わった後、ボスを倒すまでの間、
  画面全体にアウトライン表現がかかり続ける。

### DepthBasedOutline

ロックオン操作を行っている間、奥行き情報をもとにしたアウトライン（輪郭強調）表現を
画面全体にかけ、ターゲットを捕捉している最中であることを演出した。

- 確認方法: ロックオン操作を行っている間、画面全体にアウトラインがかかる。
  ロックオンを解除すると通常表示に戻る。

### RadialBlur

敵を撃破した瞬間、その敵がいた画面上の位置を中心に、約0.25秒間だけ画面全体に
放射状のぼかし（歪み）をかけ、ヒットした手応えを演出した。

- 確認方法: 敵を倒すと、その位置を中心に画面が一瞬歪む。

### Dissolve

敵を撃破した際、モデルをその場で瞬時に消すのではなく、輪郭が光りながら
少しずつ消えていく（溶解する）ような表現で撃破演出とした。

- 確認方法: 敵を倒すと、モデルが一瞬で消えるのではなく、縁が光りながら徐々に消えていく。

### Random

敵を5体撃破するごとに、約0.4秒間だけ画面全体にランダムなノイズ（グリッチ）を表示し、
連続撃破を演出として強調した。

- 確認方法: 敵を連続して倒していくと、5体目・10体目…を倒した瞬間に、
  画面に一瞬ノイズ状のグリッチがかかる。
