# 加点要素

## Skinningモデルの表示

プレイヤーのモデルを、骨あり(Skinning対応)のgltfモデルに差し替え、常に歩行アニメーションを
再生した状態で表示するようにした。

- 確認方法: GameSceneをPlayすると、プレイヤーキャラクターが骨ありモデルとして表示され、
  歩行アニメーションが再生される。

## ComputeShaderによるスキニング

頂点のスキニング処理をCPUで計算するのではなく、ComputeShaderに頂点データとボーン行列を渡し、
GPU側で並列にスキニング後の頂点位置を計算してから描画する。

- 確認方法: 上記のSkinningモデルが正しく変形・アニメーションしていること自体が、
  GPU側で計算されたスキニング結果を描画に使っていることの確認になる。

## MultiMesh & MultiMaterial対応

複数メッシュ・複数マテリアルで構成されたモデルを、1つのオブジェクトとして正しく描画できる
ように対応した。読み込んだモデルの元のメッシュ単位で描画範囲（インデックスの開始位置と個数）
を計算しておき、描画時にその範囲ごとに対応するマテリアルのテクスチャへ切り替えながら個別に
描画する。単一メッシュのモデルは従来通り1回の描画で済ませるため、既存アセットの見え方には
影響しない。

- 確認方法: GameScene内、プレイヤー付近に常時配置されている装飾オブジェクトに近づくと、
  同一オブジェクトの異なる部位に、見た目が大きく異なる2種類のテクスチャ（市松模様風の柄と
  カラフルなUVチェッカー柄）が同時に表示されているのが確認できる。

## Animation補間

アニメーションの遷移時に、旧アニメーションのポーズと新アニメーションのポーズを
`t*B + (1-t)*A` の式でLerp（平行移動・スケール）/Slerp（回転）によりブレンドしながら
遷移させることで、瞬間切り替えではなく滑らかなクロスフェードを実現した。遷移開始時の
ポーズをスナップショットしておき、遷移が完了するまでの間だけ2つのポーズを混ぜ合わせる。

- 確認方法: GameScene内でロックオン操作をON/OFFすると、プレイヤーの歩行モーションが
  瞬間的に切り替わらず、滑らかにクロスフェードしながら別のモーションへ移行する。

## 骨のデバッグ表示

プレイヤーモデルの骨格（スケルトン）構造を、各ボーンの現在のワールド座標を求め、親子関係に
沿って線を結ぶことでデバッグ描画する。アニメーションによってボーンが動けば、その動きに合わせ
て線も追従する。

- 確認方法: GameScene内で **Bキー** を押すと、プレイヤーの骨格が線で表示され、
  アニメーションに合わせて動く。

## 手からパーティクルを出す

指定したボーン名から、そのボーンの現在のワールド座標を取得できる仕組みを追加し、弾を発射する
際に自機の中心座標ではなく、右手ボーンの座標からマズルフラッシュのパーティクルおよび弾を
発生させるようにした。

- 確認方法: GameScene内で弾を発射すると、自機の中心ではなく右手の位置からパーティクルと
  弾が発生する。

## 武器を手に持たせる

上記の「ボーンのワールド座標を取得する仕組み」を流用し、武器（仮モデル）を毎フレーム右手
ボーンの座標に配置し直すことで、アニメーション中も手に持ったまま追従させている。なお、ボーン
の行列にはスキニング用の非常に小さいスケール成分が含まれているため、行列をそのまま使うと
武器がほぼ見えないサイズまで縮んでしまう問題があり、座標（平行移動成分）だけを取り出して
スケールを組み直すことで正しい大きさで表示されるように調整した。

- 確認方法: GameScene内で、プレイヤーの右手に武器（仮モデル）が追従して表示され、
  アニメーション中も手からズレずに動く。

## GPU Particle

GPU Particleシステムを拡張し、以下に対応した。

- 複数のエミッタを同時に運用できるようにし、常駐用のエミッタとは別に、ヒット時などに使い回す
  ためのバースト専用のエミッタ枠を用意（ラウンドロビンで使い回す）。
- エミッタの形状として球形（Sphere）と直方体（Box）の2種類に対応。
- Field（Attractor：吸引、Wind：一定方向の力、Vortex：渦）を追加し、パーティクルの動きに
  外力を加えられるようにした。
- エミット処理を、エミッタ1つにつき1スレッドグループを割り当てる形に並列化し、複数エミッタを
  同時に処理できるようにした。

- 確認方法:
  - GameScene内、プレイヤー付近に、直方体形状の常駐エミッタとVortex Fieldによって渦を巻く
    パーティクルが常時表示されている。
  - 敵を撃破すると、その位置でGPU Particleのバーストが発生する（パーティクルごとにランダム
    な色が割り当てられるため、虹色にきらめいて見える。同時に発生する既存のCPU側爆発
    パーティクル（白色固定）とは見た目で区別できる）。
